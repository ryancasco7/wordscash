# WordsCash 💰

A word game where you spell words from given letters and earn cash/points — powered by Claude AI for real-time word validation.

## 🎮 How to Play

1. Enter your name and click **Start Playing**
2. Tap letter tiles to spell a word
3. Click **Submit Word** — Claude AI validates it in real time
4. Longer words = more points = more cash!
5. 5 rounds, 2 minutes each — go for the high score!

## 💡 Scoring

| Word Length | Multiplier |
|-------------|------------|
| 2–3 letters | 1× |
| 4 letters | 1.5× |
| 5 letters | 2× |
| 6–7 letters | 3× |
| 8+ letters | 4× |

Each point = $0.01 cash earned.

## 🛠 Tech Stack

- Vanilla HTML/CSS/JS — zero dependencies
- Claude AI API (claude-sonnet-4) for word validation
- Deploy anywhere: GitHub Pages, Vercel, Netlify

## 🌐 Deploy on GitHub Pages

1. Go to repo **Settings → Pages**
2. Set source to **main branch / root**
3. Your game will be live at https://ryancasco7.github.io/wordscash
